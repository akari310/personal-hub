# Web Dev Basics

## HTML Structure
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <h1>Hello World</h1>
</body>
</html>
```

## CSS Flexbox

```css
.container {

    justify-content: center;
    align-items: center;
    gap: 1rem;
}
```
